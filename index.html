📖 Petunjuk Integrasi Google Spreadsheet

Ikuti langkah-langkah di bawah ini untuk menghubungkan aplikasi Rekap Absensi Siswa ke Google Spreadsheet:

  1. Buka Google Spreadsheet baru di sheets.google.com.
  2. Klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus semua kode di editor Apps Script, lalu tempelkan (paste) kode di bawah ini:
  1. Klik tombol Terapkan (Deploy) → Penerapan baru (New deployment).
  2. Pilih jenis: Aplikasi web (Web app).
  3. Atur Jalankan sebagai (Execute as): Saya (Me).
  4. Atur Siapa yang memiliki akses (Who has access): Siapa saja (Anyone).
  5. Klik Terapkan (Deploy), berikan izin akses jika diminta, lalu salin URL Web App yang dihasilkan.
  6. Tempelkan URL Web App tersebut ke kolom URL Google Apps Script di Pengaturan aplikasi ini.
