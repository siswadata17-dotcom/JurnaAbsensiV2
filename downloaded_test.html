📊 Integrasi Google Spreadsheet
💡 Tempelkan Web App URL dari Deployment Google Apps Script untuk sinkronisasi data absensi secara otomatis.
📘 Petunjuk Lengkap & Kode Google Apps Script (GAS)
Langkah Integrasi Google Spreadsheet & Google Apps Script:
  1. Buat Spreadsheet Baru: Buka Google Sheets dan buat spreadsheet baru.
  2. Buka Script Editor: Klik menu Ekstensi (Extensions) > Apps Script.
  3. Tempelkan Kode: Hapus semua kode default, lalu salin dan tempelkan kode JavaScript di bawah ini:
  1. Simpan & Apply Deployment: Klik tombol Simpan (💾), lalu klik Penerapan (Deploy) > Penerapan Baru (New deployment).
  2. Atur Akses:
    • Pilih jenis: Web app.
    • Jalankan sebagai (Execute as): Me (Saya).
    • Siapa yang memiliki akses (Who has access): Anyone (Siapa saja).
  3. Izinkan Akses: Klik Deploy, lalu klik Authorize access dan izinkan akun Google Anda.
  4. Salin Web App URL: Salin URL Web App yang berakhiran /exec, lalu tempelkan pada kolom URL di atas dan klik Simpan Semua.
  5. Mulai Sinkronisasi: Klik tombol ☁️ Sync Google pada toolbar utama kapan saja untuk mensesuaikan data absensi ke Spreadsheet.
